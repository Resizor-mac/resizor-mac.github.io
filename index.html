Resizor for Mac

Resizor is a precise developer tool for resizing images to generate icon sets and launch images for macOS and iOS. Drag in your source image, define sizes, and export ready-to-use assets for Xcode projects.

Drag and Drop Simplicity

Drop your source image directly into the well. No complex workflows—just intuitive interaction to start resizing instantly.

Customizable Sizes

Use built-in defaults for macOS icons and iOS launch images, or add your own. Settings persist across sessions for consistent efficiency.

One-Click Exports

Save individual icon sets or full Images.xcassets folders optimized for Xcode import. Supports both macOS and iOS targets seamlessly.

Version 1.0.6

Enhanced stability, macOS compatibility, and performance for reliable daily use in your development workflow.

Precise Asset Generation

Generate high-quality icons and launch images at exact specifications, ensuring pixel-perfect results for App Store submissions.

How It Works

Step 1

Drag your source image onto the image well.

Step 2

Adjust sizes using defaults or custom entries—saved for next time.

Step 3

Click Save Icons for sets, or Save Images.xcassets for Xcode-ready folders.

Step 4

Select output folder and import directly into your project.
